## [0.1.0] — Initial release (draft)

### Added
- FastAPI backend with job-based pipeline orchestration
- React frontend with chat interface, job status, and Google Drive/YouTube OAuth
- Reference video analysis (EasyOCR, PaddleOCR, SceneDetect)
- AI-assisted edit planning via Groq conversational brief builder
- Shotstack timeline assembly and cloud rendering integration
- Shorts conversion (16:9 → 9:16 reframe and post-processing)
- YouTube upload via OAuth 2.0
- Google Drive asset ingestion (service account and OAuth)
- Unit tests: normalization, overlay policy, text segments
- Dockerfile for containerized deployment
